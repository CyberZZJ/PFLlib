# 差分隐私保护验证计划

## 验证目标
按照学术标准验证 DP-Prox 和 DP-Native-FedProx 方案是否成功保护了隐私。

## 学术验证方法

### 1. 隐私预算计算与验证
- **方法**：基于高斯机制的理论计算
- **原理**：验证噪声尺度是否符合 (ε, δ)-DP 要求
- **工具**：数学公式计算

### 2. 敏感度分析
- **方法**：计算模型更新对输入数据的敏感度
- **原理**：验证梯度裁剪是否有效控制敏感度
- **工具**：计算相邻数据集的模型更新差异

### 3. 成员推理攻击测试
- **方法**：训练成员推理攻击模型
- **原理**：测试攻击者能否推断数据是否属于训练集
- **工具**：攻击模型训练与评估

### 4. 差分隐私统计验证
- **方法**：Dwork 等人的差分隐私定义验证
- **原理**：验证输出分布在相邻数据集上的差异
- **工具**：统计距离计算

### 5. 合成数据测试
- **方法**：生成合成数据并测试隐私泄露
- **原理**：验证模型是否泄露训练数据信息
- **工具**：合成数据生成与分析

## 验证计划

## [x] Task 1: 隐私预算计算与验证
- **Priority**: P0
- **Depends On**: None
- **Description**:
  - 计算两个方案的理论隐私预算
  - 验证噪声尺度设置是否合理
  - 分析隐私预算与噪声尺度的关系
- **Success Criteria**:
  - 隐私预算计算正确
  - 噪声尺度符合理论要求
- **Test Requirements**:
  - `programmatic` TR-1.1: 计算理论隐私预算
  - `programmatic` TR-1.2: 验证噪声尺度与隐私预算的关系

## [x] Task 2: 敏感度分析
- **Priority**: P0
- **Depends On**: Task 1
- **Description**:
  - 生成相邻数据集（仅差一个样本）
  - 计算两个数据集上的模型更新差异
  - 验证梯度裁剪是否有效控制敏感度
- **Success Criteria**:
  - 敏感度被有效控制在裁剪阈值内
  - 相邻数据集的模型更新差异小于裁剪阈值
- **Test Requirements**:
  - `programmatic` TR-2.1: 计算相邻数据集的模型更新差异
  - `programmatic` TR-2.2: 验证敏感度控制效果

## [ ] Task 3: 成员推理攻击测试
- **Priority**: P1
- **Depends On**: Task 1, Task 2
- **Description**:
  - 训练成员推理攻击模型
  - 测试攻击模型在两个方案上的性能
  - 与非隐私保护的基线进行对比
- **Success Criteria**:
  - 成员推理攻击准确率接近随机猜测
  - 与基线相比攻击性能显著下降
- **Test Requirements**:
  - `programmatic` TR-3.1: 训练成员推理攻击模型
  - `programmatic` TR-3.2: 评估攻击准确率

## [x] Task 4: 差分隐私统计验证
- **Priority**: P1
- **Depends On**: Task 1, Task 2
- **Description**:
  - 生成大量模型输出样本
  - 计算相邻数据集上输出分布的统计距离
  - 验证统计距离是否符合差分隐私要求
- **Success Criteria**:
  - 统计距离小于 e^ε
  - 符合差分隐私的数学定义
- **Test Requirements**:
  - `programmatic` TR-4.1: 计算输出分布的统计距离
  - `programmatic` TR-4.2: 验证统计距离是否符合要求

## [ ] Task 5: 合成数据测试
- **Priority**: P2
- **Depends On**: Task 1, Task 2
- **Description**:
  - 使用模型生成合成数据
  - 分析合成数据与训练数据的相似性
  - 验证是否存在隐私泄露
- **Success Criteria**:
  - 合成数据与训练数据无明显相似性
  - 无法从合成数据中恢复训练数据信息
- **Test Requirements**:
  - `programmatic` TR-5.1: 生成合成数据
  - `human-judgement` TR-5.2: 分析合成数据与训练数据的相似性

## [x] Task 6: 生成详细验证报告
- **Priority**: P2
- **Depends On**: All previous tasks
- **Description**:
  - 汇总所有验证结果
  - 分析两个方案的隐私保护效果
  - 提供改进建议
- **Success Criteria**:
  - 详细的验证报告
  - 明确的结论和建议
- **Test Requirements**:
  - `human-judgement` TR-6.1: 报告内容完整清晰
  - `human-judgement` TR-6.2: 结论有数据支持

## 实施步骤
1. **准备阶段**：设置验证环境，准备测试数据
2. **理论验证**：完成隐私预算计算和敏感度分析
3. **攻击测试**：实施成员推理攻击测试
4. **统计验证**：进行差分隐私统计验证
5. **合成数据测试**：生成和分析合成数据
6. **报告生成**：汇总结果并生成验证报告

## 预期结果
- 验证两个方案是否满足差分隐私要求
- 评估隐私保护效果的强弱
- 提供详细的验证报告和改进建议
