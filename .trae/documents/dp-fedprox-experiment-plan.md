## 实施步骤

### 步骤1: 运行DP-FedProx算法（初始参数）
**命令**: 
```bash
python system/main.py -algo DPProx -gr 20 -mu 0.01 -dp_eps 1.0 -dp_clip 1.0 -dp_noise 1.0 -sfn compare_dpprox
```

**参数说明**:
- `-algo DPProx`: 使用DP-FedProx算法
- `-gr 20`: 全局训练20轮
- `-mu 0.01`: FedProx正则化参数
- `-dp_eps 1.0`: 隐私预算ε=1.0
- `-dp_clip 1.0`: 梯度裁剪阈值C=1.0
- `-dp_noise 1.0`: 噪声乘数σ=1.0
- `-sfn compare_dpprox`: 保存结果文件夹名称

**监控指标**:
- 每轮准确率变化趋势
- 每轮训练时间
- 隐私预算消耗情况
- 收敛速度

### 步骤2: 实时监测与评估
**监测内容**:
1. 准确率是否持续上升（与FedProx基准对比）
2. 训练时间是否合理
3. 是否出现无法收敛或准确率异常下降的情况

**评估标准**:
- ✅ 准确率持续上升，收敛正常 → 继续训练，记录结果
- ⚠️ 准确率波动较大或上升缓慢 → 进入步骤3调参
- ❌ 准确率无法收敛或异常下降 → 立即停止，进入步骤3调参

### 步骤3: 参数调优（如需要）
**调参策略**: 网格搜索最优参数组合

**参数搜索空间**:
1. **近端项系数μ**: [0.001, 0.01, 0.1, 1.0]
   - μ较小: 正则化较弱，可能收敛较慢
   - μ较大: 正则化较强，可能过度约束

2. **梯度裁剪阈值C**: [0.5, 1.0, 2.0, 5.0]
   - C较小: 梯度被裁剪更多，噪声相对影响更大
   - C较大: 梯度保留更多，但隐私保护可能减弱

3. **隐私预算ε**: [0.5, 1.0]
   - ε较小: 隐私保护更强，但噪声更大，准确率可能降低
   - ε较大: 隐私保护较弱，但噪声较小，准确率可能更高

**调参顺序**:
1. 首先调整μ，观察收敛性
2. 然后调整C，平衡隐私与效用
3. 最后调整ε，在隐私预算范围内优化准确率

### 步骤4: 运行DP-Native-FedProx算法
**命令**: 
```bash
python system/main.py -algo DPProxNative -gr 20 -mu 0.01 -dp_eps 1.0 -lambda_priv 0.05 -sfn compare_dpproxnative
```

**参数说明**:
- `-algo DPProxNative`: 使用DP-Native-FedProx算法
- `-lambda_priv 0.05`: 隐私正则项系数
- 其他参数与DP-FedProx保持一致

**监控指标**: 与DP-FedProx相同

### 步骤5: 结果对比与分析
**对比维度**:
1. 准确率对比（FedProx vs DP-FedProx vs DP-Native-FedProx）
2. 训练时间对比
3. 隐私预算消耗对比（仅DP算法）
4. 收敛速度对比

**输出结果**:
- 三种算法的准确率曲线对比
- 最优参数组合
- 差分隐私合规性验证报告
- 性能权衡分析

## 风险与应对
1. **风险**: DP算法准确率过低（<60%）
   - **应对**: 增大隐私预算ε，减小噪声乘数σ

2. **风险**: DP算法无法收敛
   - **应对**: 调整μ和C参数，平衡正则化和隐私保护

3. **风险**: 训练时间过长
   - **应对**: 减少全局轮数或客户端数量进行快速验证
