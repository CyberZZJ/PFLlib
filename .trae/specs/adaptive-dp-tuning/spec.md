# 自适应差分隐私调参系统 Spec

## Why
当前实验使用固定参数进行差分隐私联邦学习训练，无法根据数据集特性和训练过程动态调整参数。需要建立一个自适应调参系统，根据数据集特性自动选择最优参数组合，并在训练过程中实时监控准确率变化，当连续3轮没有提升时自动终止训练并尝试新的参数组合。

## What Changes
- 创建自适应差分隐私调参框架，支持多数据集（MNIST、FashionMNIST）
- 实现基于数据集特性的参数推荐系统
- 添加实时准确率监控机制，连续3轮无提升时终止训练
- 实现自动参数搜索和切换逻辑
- 生成隐私预算审计报告和最优参数记录

## Impact
- Affected specs: dp-fedprox-comparison
- Affected code: 
  - 新建: `adaptive_dp_tuning.py`（主调参脚本）
  - 新建: `dataset_config.py`（数据集配置）
  - 新建: `training_monitor.py`（训练监控器）
  - 修改: `serverdpprox.py`、`serverdpproxnative.py`（支持动态参数调整）

## ADDED Requirements

### Requirement: 数据集特性配置
系统应针对不同数据集提供差异化的参数配置策略。

#### Scenario: MNIST数据集配置
- **GIVEN** 用户选择MNIST数据集
- **WHEN** 系统初始化参数配置
- **THEN** 系统应使用以下推荐参数范围：
  - ε ∈ [4.0, 5.0]（MNIST对差分隐私容忍度较高）
  - δ = 1e-5
  - 裁剪范数C ∈ [0.2, 1.0]
  - 噪声乘数σ ∈ [0.5, 1.5]
  - 预期准确率损失约0.61%（ε=5时）

#### Scenario: FashionMNIST数据集配置
- **GIVEN** 用户选择FashionMNIST数据集
- **WHEN** 系统初始化参数配置
- **THEN** 系统应使用以下推荐参数范围：
  - ε ∈ [5.0, 10.0]（FashionMNIST对噪声更敏感）
  - δ = 1e-5
  - 裁剪范数C ∈ [0.5, 2.0]
  - 噪声乘数σ ∈ [0.3, 1.0]
  - 预期准确率损失约2.59%（ε=5时）

### Requirement: 实时准确率监控
系统应在训练过程中实时监控准确率变化，并在连续3轮无提升时终止训练。

#### Scenario: 准确率监控与终止
- **GIVEN** 训练正在进行中
- **WHEN** 连续3轮准确率没有提升（或下降）
- **THEN** 系统应：
  1. 立即终止当前训练
  2. 记录当前参数组合的结果
  3. 切换到下一组参数继续训练
  4. 输出终止原因和准确率变化趋势

#### Scenario: 正常收敛
- **GIVEN** 训练正在进行中
- **WHEN** 准确率持续提升或保持稳定
- **THEN** 系统应继续训练直到达到最大轮数

### Requirement: 自动参数搜索
系统应自动搜索最优参数组合，直到找到满足条件的参数。

#### Scenario: 参数搜索策略
- **GIVEN** 需要进行参数调优
- **WHEN** 系统开始参数搜索
- **THEN** 系统应：
  1. 根据数据集特性选择初始参数范围
  2. 使用网格搜索或贝叶斯优化
  3. 对每组参数进行训练并记录结果
  4. 选择准确率最高且隐私预算满足要求的参数组合
  5. 输出最优参数和对应的性能指标

#### Scenario: 隐私预算约束
- **GIVEN** 用户指定隐私预算上限ε_max
- **WHEN** 系统选择参数
- **THEN** 系统应确保最终选择的参数组合满足ε ≤ ε_max

### Requirement: 结果报告生成
系统应生成完整的调参报告和隐私预算审计日志。

#### Scenario: 调参报告
- **GIVEN** 参数搜索完成
- **WHEN** 系统生成报告
- **THEN** 报告应包含：
  1. 数据集名称和特性
  2. 搜索的参数空间
  3. 每组参数的训练结果（准确率、训练时间、隐私预算）
  4. 最优参数组合
  5. 准确率收敛曲线
  6. 隐私预算消耗分析

## MODIFIED Requirements

### Requirement: 差分隐私参数设置
原有的固定参数设置应改为动态参数设置。

#### Scenario: 动态参数调整
- **GIVEN** 训练过程中需要调整参数
- **WHEN** 系统检测到需要切换参数
- **THEN** 系统应能够动态更新：
  - 噪声乘数σ
  - 梯度裁剪阈值C
  - 隐私预算ε
  - 近端项系数μ

无
